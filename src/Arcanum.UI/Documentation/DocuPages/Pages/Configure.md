This panel is the central menu for adding and managing mods in Arcanum.

At the bottom is an overview of your recent projects.

>[!tip] 
Double-clicking a recent project will open it directly, while single-clicking will populate the fields above with the project's settings and allow editing them. 


 Create a new project
1. Set the game file location (`.\Europa Universalis V\game`) in the top input field. You can enter the path manually or click the "Folder" icon to browse.
> [!tip] The game file location is detected automatically if installed with [Steam](https://store.steampowered.com)
> 
>
>

2. Select your mod's directory in the lower input field.
3. (**Optional**) Add base mods by clicking the green folder icon. Drag and drop mods to change their load order or remove them
4. Click the **Current Config** button in the top bar to launch Arcanum
